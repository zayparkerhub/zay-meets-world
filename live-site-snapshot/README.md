# Live site snapshot (Nov 14, 2026)

Copy of zaymeetsworld.com as it was live on this date: the dark green
"Hero Fund Holiday Giveaway" version. Its source code was never pushed to
GitHub (main still has the older white landing page), so this folder keeps
everything needed to rebuild it exactly:

- `*.html` / `*.txt`: rendered markup and text of /, /support, /privacy, /terms, /admin/login
- `holiday-styles.css`: the site's custom styles (snow, lights, ornaments, cards, social dock)
- `screenshots/`: phone and desktop screenshots, plus a short video of the motion

Pages live: / (Hero Fund), /support (Cash App / Venmo / PayPal), /privacy, /terms.
/join redirects to /. /support links to /herofund, which doesn't exist (broken link).
